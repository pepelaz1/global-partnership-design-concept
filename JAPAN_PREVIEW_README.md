# Japan partnership design concepts

This package contains **ten early visual directions** for a Japan partnership card. Each direction has a different layout and a different original, provisional icon. These are concepts for discussion, not final brand assets.

Start with `preview/japan-10-variants.jpg` to compare the complete cards, then open `preview/japan-10-icons.jpg` to compare the marks at a larger size.

The `png/` folder contains presentation images at 1600 × 900 pixels. The `svg/` folder contains editable vector versions of the same ten concepts. Text in the SVG files uses common system font families; its appearance can vary slightly between computers.

Feedback is welcome on the preferred direction, existing logo or icon assets, brand colors, fonts, wording, and any other ideas. The chosen direction can be refined before creating the remaining country versions.
